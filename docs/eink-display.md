# 墨水屏显示与动画改造

本阶段面向整个知乎水墨应用固定生效，不增加模式开关。以白底黑字为阅读基础，保留有足够对比度的强调色，以及图片和徽章的内容原色，兼顾黑白与彩色墨水屏。

## 显示约定

正文与主要表面固定为白底黑字，辅助文字使用深灰，分隔线至少使用深灰。动态取色、深浅主题切换和自定义背景入口已移除，旧配置不会覆盖固定色板。系统栏和启动窗口保持亮色。

底部导航和筛选项使用勾选、文字或边框表达选中状态，信息流选中项使用加粗边框。设置分组行增加轮廓，搜索设置跳转的目标保持静态边框，取消闪烁及自动淡出。投票操作增加“已赞同”“已反对”等状态文字。

WebView 正文保持白底黑字，链接保留深蓝并增加下划线；图注、引用和分隔线加深。图片、徽章和正文已有的内容颜色不做全局去色。

## 动画与加载

应用自己的 Compose 窗口使用零动画时长，Material 动画规格即时完成；此策略不修改 Android 系统的全局动画设置。关闭触摸水波纹和弹性过度滚动，主动翻页、回顶及脚注跳转直接到达，图片关闭淡入。

文章呼吸占位与不确定进度加载改为静态提示。空间足够时显示“正在加载…”等文字；紧凑按钮内使用静态沙漏并提供可访问的状态描述。下拉刷新按状态显示“下拉刷新”“松开刷新”“正在刷新…”，确定进度仍展示真实进度条。

## 范围与验证边界

本阶段不接入厂商刷新 SDK，不控制全刷、局刷、刷新频率，也不改变图片和视频内容的色彩能力。

本地验证仅做编译、单元测试和静态代码检查；按项目约定不进行本地视觉复核。新增单元测试检查白底黑字、辅助文字和线条对比度、彩色强调色保留，以及零动画规格。真实设备上的字号、残影、刷新体验仍需后续验收。
